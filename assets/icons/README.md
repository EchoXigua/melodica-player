# Melodica Studio icon

Generated with the built-in image_gen tool. source.png is the original transparent image; icon.png (1024 px), icon.icns, and multi-resolution icon.ico are platform conversions. The browser uses src/renderer/public/favicon.png.

Prompt: A near-black rounded square desktop app icon with a centered lavender-to-electric-violet emblem combining five equalizer bars and piano keys. Subtle luminous depth, crisp silhouette readable at 32 px, transparent outside the tile; no text or additional symbols.

macOS development sets the Dock icon explicitly; packaged apps use icon.icns. Windows executable resource editing must remain enabled to embed icon.ico. Changing icons requires restarting or rebuilding the application.
