## 下载选择

- **Windows**：下载 `win-x64.exe` 结尾的文件，免安装运行。
- **Mac M 系列芯片**：下载 `mac-arm64.dmg`，打开后拖入 Applications。
- **Mac Intel 芯片**：下载 `mac-x64.dmg`，打开后拖入 Applications。
- `SHA256SUMS.txt` 提供文件校验值。GitHub 自动生成的 Source code 是源码，不是安装包。

## 功能

MIDI 导入、曲谱试听、键鼠演奏、本地曲库保存、改名与拖动排序。
Mac 首次进行键鼠演奏时，请按应用提示授权辅助功能。可以先使用“键鼠测试”验证输入。

## 当前分发状态

Windows 版本没有商业代码签名；Mac 仅进行本地临时签名，未通过 Apple 公证，系统可能阻止首次打开。请核对文件来源，再使用系统提供的打开或允许入口。
本版本不包含自动更新。Mac 接收测试不替代 Windows 游戏内实际验证。
