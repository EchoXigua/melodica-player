- Swift CGEvent 引擎成功编译为 arm64 + x86_64 通用二进制；已运行测试的主机为 Apple Silicon。
- `pnpm test:mac-input`：真实接收 38 / 38 条键鼠事件（8 个琴键及左、右、中鼠标键），非可信事件 0，未释放输入 0。
